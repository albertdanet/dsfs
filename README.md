# Offline AI (iOS 15+)

Чат с ИИ, который работает полностью без интернета. Модель (Qwen2.5 Instruct, GGUF)
запускается прямо на iPhone через llama.cpp, только на процессоре.

## Как собрать .ipa

1. Создай репозиторий на GitHub и залей туда все эти файлы (включая папку `.github`).
2. Вкладка **Actions → Build IPA → Run workflow**, выбери модель:
   - `qwen2.5-1.5b`: лучше качество, около 1 ГБ (рекомендуется, если у iPhone 4 ГБ ОЗУ и больше);
   - `qwen2.5-0.5b`: быстрее и легче, но заметно слабее, особенно по-русски;
   - `none`: без встроенной модели, её нужно будет импортировать из «Файлов».
3. Когда сборка закончится, скачай артефакт `OfflineChat-ipa` и распакуй zip.
4. Установи `OfflineChat.ipa` через LiveContainer.

## Заметки

- Библиотека llama.cpp собирается из исходников (тег `b5046`) с `IPHONEOS_DEPLOYMENT_TARGET=15.0`
  и без Metal: готовый xcframework требует iOS 16.4+.
- Можно заменить модель в приложении: «Настройки → Импортировать .gguf». Подойдёт любая модель
  в формате ChatML (Qwen2.5 Instruct и подобные), лучше квантизация Q4_0.
- Контекст 2048 токенов, ответ до 512 токенов. История чата хранится в приложении.
